BUILD APK WITHOUT INSTALLING ANDROID STUDIO
===========================================

This project includes a GitHub Actions workflow that builds the APK in GitHub's cloud.
You do not need Android Studio on your computer, but you will need a GitHub account.

Steps:
1. Sign in to https://github.com/ or create a free account.
2. Create a new repository, for example: sen-billing-android.
3. Upload all files and folders from this project into the repository (including the hidden
   .github/workflows/build-apk.yml file). Keep the root files settings.gradle and build.gradle
   at the repository root, and keep the app folder at the root.
4. Open the repository's Actions tab.
5. Select "Build Sen Billing APK" on the left and click "Run workflow". If the workflow is not
   visible yet, first commit/push the files to the main branch.
6. Wait for the workflow to finish successfully.
7. Open the completed workflow run. Under Artifacts, download "Sen-Billing-debug-APK".
8. Extract the downloaded artifact ZIP. It contains app-debug.apk.
9. Transfer app-debug.apk to your Android phone and open it to install. You may need to allow
   installation from that file manager/browser when Android asks.

Notes:
- This creates a debug/test APK, not a Play Store release APK.
- Before sharing with customers, test login, billing, printing, uploads, downloads and external
  links on real devices. A Play Store release needs a signed release build and store compliance.
- Never upload passwords, signing keys, API secrets, or customer data to a public repository.
